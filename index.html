24 Shot Clock Project & Logic Circuits

Digital Logic & Circuit Design

Designed and implemented a 24-second shot clock using programmable logic, counters, and timing circuits. The project included building the display driver, reset and start controls, and timekeeping logic to maintain accurate countdown operation for game play.

Developed the solution by applying boolean algebra, Karnaugh map simplification, and sequential circuit theory. The finished design demonstrates how logic gates, flip-flops, and debounced input switches work together to produce a reliable sport timing system. I also integrated error detection for missed button presses and added a visual status indicator to show active countdown states. This strengthened the design's usability and showed how circuit behavior maps directly to practical user interactions.
